# Olist E-Commerce End-to-End Data Engineering Pipeline

## Project Overview

This project builds an end-to-end data engineering pipeline
for Brazilian e-commerce data from Olist.

The pipeline covers:

- Data ingestion
- Data profiling
- Data validation
- PySpark transformation
- SQL analytics
- Data quality
- Automation
- Apache Airflow orchestration
- GCP integration

## Technology Stack

- Python
- Pandas
- PySpark
- SQL
- Linux
- Shell Scripting
- Git
- Apache Airflow
- GCP
- BigQuery
- Parquet
